# PowerBI-Pizza-Sales-Dashboard
I recently completed an end-to-end data analysis project using the Maven Analytics "Pizza Place Sales" dataset. The goal was to build an interactive Power BI dashboard that helps a restaurant manager identify peak operational hours, best-selling menu items, and underperforming pizzas.

Key Features & Technical Highlights:

Advanced DAX: Solved complex average calculations (e.g., Average Orders per Hour) by correctly utilizing filter contexts with DIVIDE and DISTINCTCOUNT over specific dates and order IDs.

Dynamic Parameters: Implemented "What-If" parameters allowing users to dynamically filter and rank the Top N (Bestsellers) and Bottom N (Worst sellers) pizzas.

Data Modeling: Handled custom chronological sorting for text-based day names to fix alphabetical sorting issues.

UI/UX Design: Applied "Data-Ink Ratio" principles, custom conditional formatting, and a dark theme to create a clean, modern, and business-ready interface.

Tools Used: Power BI, DAX, Power Query.
